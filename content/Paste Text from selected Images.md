This shortcut is used to select a number of photos, OCR the text in them, concatenate the string and past the result in the current note. It takes the following actions:

- Define a separator between the text (--- results in a horizontal line)
- Select as many photos as you want
- Extract the text from the photos
- Repeat - for every photo - concatenate the text with separators in between
- Run the "Paste" workflow to insert the result in the note
